# BraveLite-Portable

Windows 用 Brave Stable 免安裝便攜啟動器。

## 使用方式

1. 下載並解壓縮 [最新 Release](https://github.com/falaisy/BraveLite-Portable/releases/latest)。
2. 確認 `BraveLite.bat` 和 `BraveLite.ps1` 放在同一個資料夾。
3. 執行 `BraveLite.bat`，依照畫面選單操作。

首次使用時，程式會從 Brave 官方來源下載 Stable 版本並部署；之後可用來啟動 Brave、檢查完整性及更新版本。

不需要另外安裝 Brave，也不需要管理員權限。

## 注意事項

- 請勿分開或刪除 BAT、PS1 任一檔案。
- 請使用 Brave 官方來源取得的瀏覽器版本。
- 本專案僅供作者個人興趣使用，不鼓勵他人下載或使用；若自行使用，請自行承擔相關風險。
